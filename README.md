# Royal Morocco Travels

A responsive Next.js App Router website with WhatsApp booking requests.

## Development

Use Node.js 20.9 or later and pnpm. Run `pnpm install`, then `pnpm dev`.
Run `pnpm build` for a production static export in `out/`.

Bookings open WhatsApp at +212 644 643 319 with the selected journey, date, and group size. No payment is collected and no reservation is confirmed automatically. Journey durations are inspiration, not confirmed packages; availability and quotes are agreed directly with the agency.

Edit journey content and the WhatsApp number in `app/page.tsx`. Global styling is in `app/globals.css`.

The homepage carousel includes five destinations with pause/play, direct slide selection, previous/next controls and touch swipes. Automatic rotation respects reduced-motion preferences and pauses when interacting or when the tab is hidden.

The six traveler reviews were transcribed from screenshots supplied by the agency. Relative dates and review-count metadata were omitted to avoid becoming stale. The translated review retains its translation attribution. These selected reviews are not presented as an aggregate business rating.
